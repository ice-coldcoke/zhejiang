# 低空无人机飞行轨迹采集平台

## 项目概述
本项目是**自研低空无人机飞行轨迹采集平台**，基于 AirSim 仿真环境搭建，面向智能交通、无人机路径规划、低空安全管控等研究场景，实现城市空域下无人机飞行轨迹的高精度采集、地图场景适配与数据标准化存储。

平台依托城市地图文件构建真实仿真环境，输出可直接用于深度学习模型训练（如图异常检测、轨迹预测）的无人机轨迹数据，为智能交通领域的无人机应用研究提供核心数据支撑。

## 目录文件说明
本项目核心文件及目录功能如下，结合文件上传记录，各模块分工明确：

| 文件名 / 目录名 | 类型 | 核心功能 | 备注 |
|-----------------|------|----------|------|
| `airsim/` | 目录 | 无人机轨迹数据存储 | 包含仿真过程中采集的无人机飞行轨迹原始数据（如位置、速度、姿态、时间戳等），支持多场景、多任务下的轨迹数据分类存储，数据格式兼容 AirSim 原生输出与自定义标准化格式，可直接用于轨迹异常检测、路径优化等算法研究。 |
| `citymapzj/` | 目录 | 城市地图核心文件 | 存储城市空域仿真地图文件，包含地形地貌、建筑轮廓、交通路网（如公交站点、道路走向）、禁飞区域等关键地理信息，适配低空无人机飞行场景的地图轻量化与高精度渲染需求，是搭建仿真环境的基础。 |

## 核心功能
### 1. 高精度轨迹采集
基于 AirSim 仿真平台，实时采集无人机在城市空域中的飞行轨迹数据，记录经纬度、高度、航速、航向角等多维特征，支持时序轨迹数据的连续存储与断点续采。

### 2. 城市场景适配
通过 `citymapzj/` 的地理数据与 `NoLod_0.glb` 的 3D 模型，快速构建自定义城市低空仿真场景（如北京市通州区公交网络覆盖空域），支持建筑、路网、禁飞区等要素的灵活配置。

### 3. 数据兼容性强
输出的轨迹数据格式兼容深度学习框架，可直接用于图异常检测（如 GCN 模型）、多目标线路优化（如 ACO、SVM 算法）等智能交通领域的研究工作。

## 快速使用指引
### 环境依赖
- AirSim 1.5.0 及以上版本
- Unreal Engine 4.27/5.0（可选，用于地图可视化调试）
- Python 3.8+（用于轨迹数据解析与预处理）

### 核心步骤
1.  **地图加载**：将 `citymapzj/` 目录下的地图文件与 `NoLod_0.glb` 模型文件放入 `citymap/` 目录，完成仿真地图的配置关联。
2.  **仿真启动**：启动 AirSim 仿真引擎，加载 `citymap/` 目录中的地图工程，初始化无人机飞行参数（起飞点、飞行高度、航速等）。
3.  **轨迹采集**：运行飞行控制脚本（或手动操控无人机），轨迹数据将自动实时写入 `airsim/` 目录。
4.  **数据使用**：从 `airsim/` 目录读取轨迹数据，结合研究需求进行时序特征提取、异常检测或路径优化分析。
